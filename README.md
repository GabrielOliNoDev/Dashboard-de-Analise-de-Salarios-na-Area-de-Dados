# Dashboard-de-Analise-de-Salarios-na-Area-de-Dados
Aqui você vera uma analise feita pela imersão da Alura em Analise de Dados com Pyhton, usamos um DataFrame que possui dados relacionados ao salario das areas

- Usamos o "colab" para entender e analisar o nosso dataset, você pode ver todo o codigo em "Imersao_dados_c_Python_alura.ipynb".

- Utilizamos o Visual Studio Code para montar o dashboard, apresentar as informações atraves dos gráficos.

- Acessar o dashboard feito utilizando o streamlit -> https://imersao-dados-com-python-alura-1.streamlit.app/
